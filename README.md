# LaTeX with Inkscape in Docker
This container includes `texlive-full` without any `*-doc` packages,
and Inkscape for converting SVG images to PDF.
Pandoc is also included for convenience.

This container is used for the LaTeX compilation of
[my second master's thesis](https://github.com/AgenttiX/msc-thesis2).

The container image is available on
Docker Hub as
[`agenttix/nginx`](https://hub.docker.com/repository/docker/agenttix/latex/general),
and on GitHub Container Registry as
[`ghcr.io/agenttix/nginx`](https://github.com/agenttix/docker-latex/pkgs/container/latex).
